## 1.1. Ray Marching

Ray Marching（光线行进）技术是一种在计算机图形学中常用的渲染技术，特别适合在shader中实现3D场景渲染。以下是它的主要特点和工作原理：

1. 基本概念：
   - Ray Marching是一种基于光线追踪的渲染技术
   - 它通过在光线方向上逐步"行进"来检测与场景中物体的相交
   - 使用SDF（有符号距离函数）来判断当前点是否在物体内部或外部

2. 工作原理：
   - 从相机位置发射光线
   - 沿着光线方向以一定步长前进
   - 在每一步使用SDF计算当前点到最近物体表面的距离
   - 如果距离小于某个阈值，认为找到了相交点
   - 如果超过最大步数或距离过远，则认为没有相交

3. 优点：
   - 可以轻松渲染复杂的几何形状
   - 支持软阴影和环境光遮蔽
   - 适合实现各种特效，如体积光、折射等
   - 代码简洁，实现相对简单

4. 缺点：
   - 计算开销较大
   - 性能与场景复杂度和精度要求相关
   - 可能出现伪影（如果步长选择不当）

5. 常见应用：
   - 分形渲染
   - 程序化生成的场景
   - 特效制作
   - 实时3D图形

###  1.1.1. 球体

球体的数学公式为 
$$
(x - x_0)^2 + (y - y_0)^2 + (z - z_0)^2 = r^2
$$
其中 $(x_0, y_0, z_0)$ 是球体的中心点，$r$ 是球体的半径。
在3D空间中，我们可以将球体的SDF定义为：
$$
SDF_Sphere(p, c, r) = \sqrt{(p.x - c.x)^2 + (p.y - c.y)^2 + (p.z - c.z)^2} - r
$$

我们在 [desmos](https://www.desmos.com/3d?lang=zh-CN) 来验证一下

#### 1.1.1.1. SDF
          
在3D图形学中，球体的SDF（有符号距离函数）公式为：

对于一个半径为r的球体，其SDF公式为：
```
f(p) = |p| - r
```
其中：
- p 是一个三维向量，表示从球心到当前点的向量
- |p| 表示向量p的长度（即点到球心的距离）
- r 是球体的半径

这个公式的含义是：
- 当点在球体内部时，返回负值
- 当点在球体表面时，返回0
- 当点在球体外部时，返回正值

在GLSL中的实现通常如下：
```glsl
float sphereSDF(vec3 p, float r) {
    return length(p) - r;
}
```

这个SDF函数在Ray Marching中非常有用，因为它可以：
1. 精确描述球体的形状
2. 计算效率高
3. 便于实现球体的混合和变形
4. 可以轻松实现阴影和光照效果

#### 1.1.1.2. 示例

![](https://easyimage.elyt.cn/i/2025/04/26/5727937538094536608-2.webp)  

注：由于没有采用光照，这个球体看起来不象是球体，而象一个圆。 
**核心代码**
```cpp

float rayMarch(vec3 ro, vec3 rd,float start,float end)
{
    float d=start;
    float r=1.0;
    vec3 offset=vec3(0.5,0.5,0);
    for(int i=0;i<MAX_STEPS;i++)
    {
        vec3 p=ro+rd*d;

        float d1=sdfCircle(p,r,offset);
        if(d1<EPSILON)
        {
            return d;
        }
        d+=d1;
        if(d>end)
        {
            return end;
        }
    }
    return end;
}
```
每次行进的距离为d1,如果d1小于EPSILON,则认为找到了相交点,返回d。
如果d大于end,则认为没有相交,返回end。

本例中，MAX_STEPS 为最大行进步数，实际测试中，MAX_STEPS=2 时，也能将球体渲染出来。

**完整代码**

```cpp
#define PIXW (1./iResolution.y)

const int MAX_STEPS = 100;
const float START_DIST = 0.001;
const float MAX_DIST = 100.0;
const float EPSILON = 0.0001;


float sdfCircle(vec3 p, float r,vec3 offset)
{
    return length(p-offset)-r;
}

vec3 getBackgroundColor(vec2 uv)
{
//uv.y [-1,1]
//y: [0,1] 
    float y=(uv.y+1.)/2.; 
    return mix(vec3(1,0,1),vec3(0,1,1),y);
}

float rayMarch(vec3 ro, vec3 rd,float start,float end)
{
    float d=start;
    float r=1.0;
    vec3 offset=vec3(0.5,0.5,0);
    for(int i=0;i<MAX_STEPS;i++)
    {
        vec3 p=ro+rd*d;

        float d1=sdfCircle(p,r,offset);
        if(d1<EPSILON)
        {
            return d;
        }
        d+=d1;
        if(d>end)
        {
            return end;
        }
    }
    return end;
}

void mainImage( out vec4 fragColor, in vec2 fragCoord )
{
     // Normalized pixel coordinates (from -1 to 1)
     vec2 uv = (2.0*fragCoord-iResolution.xy)/iResolution.xx;

     
     float r=0.3;
     vec3 c=getBackgroundColor(uv);
     float d=rayMarch(vec3(0,0,5),vec3(uv,-1),START_DIST,MAX_DIST);
     if(d<MAX_DIST)
     {
        c=vec3(1,0,0);
     }
    // Output to screen
     fragColor = vec4(vec3(c),1.0);
}
```
