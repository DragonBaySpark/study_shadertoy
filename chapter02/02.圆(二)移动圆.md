
## 1. 移动圆

### 1.1. 圆的方程



圆的方程是：\(（x-offsetX)^2 + (y-offsetY)^2 = r^2\)，其中\(r\)是圆的半径。
我们可以使用 [desmos](https://www.desmos.com/calculator?lang=zh-CN) 来验证一下。
\(（x-1)^2 + (y-1)^2 -1=0\)
类似下图 

![](https://easyimage.elyt.cn/i/2025/04/26/5727832214196982695-2.webp)  


### 1.2. 思路 
1. 将uv坐标转换成圆心坐标 `(x,y) = (uv.x-offsetX,uv.y-offsetY)`
2. 计算 `(x,y)` 到圆心的距离 `d`
3. 如果 `d` 小于半径 `r`，则为白色，否则为黑色。



### 1.3. 将圆心移动到(0.3,0.3)
![](https://easyimage.elyt.cn/i/2025/04/26/5727833893776659790-2.webp)

```cpp
#define PIXW (1./iResolution.y)

vec3 sdfCircle(vec2 uv, float r,vec2 offset)
{
     uv=uv-offset;
     float d=length(uv)-r;
     return d>0.?vec3(0.):vec3(1.);
}
void mainImage( out vec4 fragColor, in vec2 fragCoord )
{
     // Normalized pixel coordinates (from -1 to 1)
     vec2 uv = (2.0*fragCoord-iResolution.xy)/min(iResolution.x,iResolution.y);

     float r=0.3;
     vec3 c=sdfCircle(uv,r,vec2(0.3,0.3));
    // Output to screen
     fragColor = vec4(vec3(c),1.0);
}

```

### 1.4. 让圆动起来
![](https://easyimage.elyt.cn/i/2025/04/26/5727839882131282684.gif)  

**思路：**
1. 让圆的圆心坐标随着时间变化
2. 让圆的颜色随着时间变化
```cpp
#define PIXW (1./iResolution.y)

vec3 sdfCircle(vec2 uv, float r,vec2 offset)
{
     uv=uv-offset;
     float d=length(uv)-r;
     return d>0.?vec3(0.):vec3(abs(sin(iTime*0.3)),abs(cos(iTime*0.3)),abs(sin(iTime*0.3)));
}
void mainImage( out vec4 fragColor, in vec2 fragCoord )
{
     // Normalized pixel coordinates (from -1 to 1)
     vec2 uv = (2.0*fragCoord-iResolution.xy)/min(iResolution.x,iResolution.y);

     float r=0.3;
     vec3 c=sdfCircle(uv,r,vec2(0.+sin(iTime)*0.2,0.+cos(iTime)*0.2));
    // Output to screen
     fragColor = vec4(vec3(c),1.0);
}
```

### 1.5. 画两个圆
**思路：**
1. 背景为黑色，即vec(0.,0.,0.)
2. 圆为非黑色
3. 两个圆的颜色相加，由于这两个圆没有重叠，所以颜色相加后，刚好会显示出两个圆

注： 这种方法，只适用于两个圆没有重叠且背景色为黑色这种简单情况。后续会说明更通用的方法。

![](https://easyimage.elyt.cn/i/2025/04/26/5727850095769032260-2.webp)  
```cpp
//显示两个圆
#define PIXW (1./iResolution.y)

vec3 sdfCircle(vec2 uv, float r,vec2 offset)
{
     uv=uv-offset;
     float d=length(uv)-r;
     return d>0.?vec3(0.):vec3(abs(sin(iTime*0.3)),abs(cos(iTime*0.3)),abs(sin(iTime*0.3)));
}
void mainImage( out vec4 fragColor, in vec2 fragCoord )
{
     // Normalized pixel coordinates (from -1 to 1)
     vec2 uv = (2.0*fragCoord-iResolution.xy)/min(iResolution.x,iResolution.y);

     float r=0.3;
     vec3 c=sdfCircle(uv,r,vec2(0.5,0.5));
     c=c+sdfCircle(uv,r,vec2(-0.5,0.5));
     //c=max(c,sdfCircle(uv,r,vec2(-0.5,0.5)));
    // Output to screen
     fragColor = vec4(vec3(c),1.0);
}
```
